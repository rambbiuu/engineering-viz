FM sidebands, Bessel functions and Carson's rule

One tone wobbling one carrier makes an endless comb of sidebands whose heights are Bessel functions. Push harder and the power reshuffles along the comb — the carrier itself can vanish.

Worked example — mono FM broadcast
  1. Allowed peak deviation Δf = 75 kHz, audio to fm = 15 kHz.
  2. Modulation index β = Δf / fm = 75 / 15 = 5, the peak phase swing in radians.
  3. Carson's rule: BW = 2(Δf + fm) = 2(75 + 15) = 180 kHz.
  4. 1 % rule: last coefficient at or above 0.01 is J8(5) = 0.0184, so n′ = 8 and BW = 2 × 8 × 15 = 240 kHz.
  5. The regulator sides with neither: broadcast channels are spaced 200 kHz apart.
  6. —
  7. Single-tone FM output SNR: S0/N0 = 3Ac2β2 / (4ηfm), with η the one-sided noise PSD in W/Hz.
  8. That β2 advantage collapses below ≈ 10 dB input SNR — the capture threshold.
What this model simplifies

Carson's rule captures about 98 % of the power, so it under-estimates the true occupied width; the 1 % rule is stricter. Section 1 draws the carrier at only 16 × fm so the squeeze is visible; a real carrier is thousands of times higher.

Glossary
Carrier
The steady high-frequency wave sent with no message. Its frequency is fc.
Sideband
An extra spectral line either side of the carrier, at fc + n·fm.
Line spectrum
Which frequencies a signal contains and how strong each one is, drawn as vertical stems.
Peak deviation Δf
The furthest the instantaneous frequency strays from fc. Set by loudness, not by pitch.
Modulation index β
Δf divided by fm, equivalently the peak phase swing in radians.
Bessel function Jn(β)
Gives the height of the nth sideband. Exact, not an approximation.
Carrier null
A β where J0 is zero, so the centre line vanishes. The first is β = 2.405.
Constant envelope
The wave's peak height never varies, so the receiver can discard amplitude noise.
