FDMA, TDMA, CDMA and OFDMA

Four ways for many phones to share one block of spectrum: split it by frequency, by time, by code, or by tiles of both. Every split costs overhead, and here that cost is drawn to scale.

New to this? Start with cellular reuse, then OFDM subcarriers.

An everyday picture. One room, many conversations. FDMA gives each pair its own soundproof booth. TDMA lets one pair speak at a time and rotates. CDMA has everyone talk at once in a different language. OFDMA hands out short turns on a mixing desk, moment by moment.

        Where this model is simplified

        Raise the guard band and FDMA loses spectrum for good; shorten the frame and TDMA loses time the same way, while CDMA's only overhead is the spreading that buys its reuse factor of one.

        Six places. Btotal is treated as covering both link directions, so every channel count is halved to get calls; a real CDMA pole capacity is quoted per direction, which makes the call figure here conservative by about a factor of two. Rappaport's N = (Btotal − 2Bguard)/Bc charges one guard band at each edge of the allocation, so the separation drawn between adjacent stripes is counted inside Bc, not added to it. Symbol rate is taken as equal to bandwidth, the ideal Nyquist limit with no roll-off, so every rate here is an upper bound. OFDMA is given no extra edge guard beyond Bguard, whereas real LTE keeps about 10 % of the band clear for the emission mask. Pilot overhead is fixed at 4 resource elements in 84, the single-antenna-port LTE figure. And these are all single-cell numbers: FDMA and TDMA must divide their spectral efficiency by the cluster size, typically 7, while CDMA reuses every cell — see cellular reuse for what that costs.

        Glossary
        Multiple access
        The rule that decides which user may use which part of the shared radio resource, and when.
        FDMA
        Frequency-division multiple access. Each user gets one frequency channel and keeps it for the whole call.
        TDMA
        Time-division multiple access. Users share a wider carrier by taking one time slot each per frame.
        CDMA
        Code-division multiple access. Every user transmits over the whole band all the time, separated only by a spreading code.
        OFDMA
        Orthogonal frequency-division multiple access. The band is a fine grid of subcarrier-by-symbol tiles and a scheduler hands them out.
        Guard band
        Unused spectrum left between channels so imperfect filters do not spill into the neighbour. Measured in kilohertz.
        Guard time
        Dead time at the end of a burst so a late-arriving signal does not overlap the next slot. Measured in microseconds.
        Frame
        The repeating time structure of a TDMA carrier. GSM's frame is 4.615 ms long and holds eight slots.
        Slot
        One user's turn inside a frame. One slot per frame on one carrier is one TDMA channel.
        Burst rate
        The instantaneous bit rate a TDMA handset must transmit at during its slot, higher than its average rate by the number of slots.
        Spreading code
        A fast pseudo-random sequence multiplied onto the data. Each user has a different one, and only the matching receiver can undo it.
        Chip
        One symbol of the spreading code. Chips are much shorter than data bits, which is what widens the signal.
        Processing gain Gp
        How much wider the spread signal is than the data: W/R, equivalently Tb/Tc. It is the factor by which the receiver lifts the wanted signal out of the interference.
        Pole capacity
        The user count at which a CDMA cell's required transmit power goes to infinity. A real system loads to perhaps half of it.
        Voice activity factor v
        The fraction of a call during which someone is actually speaking, about 0.4. Silent handsets stop transmitting, so the cell holds more of them.
        Other-cell factor f
        Interference arriving from neighbouring cells, as a fraction of the interference from inside this cell. About 0.6.
        Near-far problem
        A close handset drowns a distant one because both use the same band. CDMA only works with fast transmit power control.
        Subcarrier
        One of the many narrow tones an OFDMA signal is built from. Spacing Δf = 1/Tu.
        Resource block
        The smallest lump a scheduler can hand out: 12 subcarriers by 7 symbols in LTE.
        Cyclic prefix
        A copy of a symbol's tail pasted on its front so echoes do not smear into the next symbol. Pure overhead.
        FDD
        Frequency-division duplex. Uplink and downlink sit on two different frequencies and both run continuously.
        TDD
        Time-division duplex. One frequency, alternating between the two directions, with a guard period at the turnaround.
        Code rate Rcode
        The fraction of transmitted bits that are payload rather than error-correction parity.
        Spectral efficiency
        Bits per second delivered per hertz of spectrum. The one number that compares the four schemes fairly.
