Phased-array beam pattern

The same 4 antennas run in reverse. Direction finding reads phase differences to learn an angle; a phased array writes phase differences to choose one. Feed each element the right phase and the four ripples add up in only one direction — the beam.

Try the two presets: the sparse DF spacing (0, 2.4, 10, 30) makes a razor-thin beam but leaks big sidelobes — the same reason its long baselines wrap ambiguously when receiving. The uniform λ/2 array is clean but blunt. Sparse = sharp and ambiguous, dense = clean and wide; there is no free lunch, only trade-offs.
