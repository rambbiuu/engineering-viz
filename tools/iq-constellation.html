    What each impairment does to the picture

    A phase error turns the whole picture by a fixed angle — one uncalibrated cable, one wrong phase constant. A carrier offset is a phase error that grows with time, so the picture spins; receivers run a carrier-tracking loop to freeze it. Gain imbalance stretches the picture along one axis and quadrature skew shears it, both from an imperfect 90° splitter. A DC offset shifts every cluster the same way, usually LO leakage into the mixer. Phase noise smears each dot along a circular arc rather than in all directions, which is how you tell it apart from thermal noise.

    Glossary
    I and Q
    The two numbers a receiver measures for each symbol: how much of the carrier is present, and how much of a copy of the carrier shifted by 90°. Together they give one point on a plane, which fixes both the amplitude and the phase of the symbol.
    Constellation
    The set of points a modulation scheme is allowed to send. The receiver picks whichever allowed point the received dot is nearest to.
    Symbol
    One transmitted point, held for one symbol period. A constellation of M points carries log2M bits per symbol.
    Es/N0
    Energy in one symbol divided by the noise power spectral density. All four constellations here are scaled to the same average symbol energy, so the same dB figure means the same noise cloud in every scheme.
    Symbol error rate
    The fraction of symbols the receiver decides wrongly. One symbol error usually corrupts one or two bits, so it is close to, but not the same as, the bit error rate.
    dmin
    The distance between the two closest points of the constellation. Half of it is the noise a symbol can absorb before it crosses into the wrong cell, which is why it predicts the error rate.
    Error vector magnitude (EVM)
    The rms distance between where each symbol landed and where it should have been, as a percentage of the rms symbol amplitude. One number that folds noise, phase error and hardware imperfections together.
    Decision boundary
    The line halfway between two neighbouring constellation points. A dot that crosses it is decoded as the other symbol.
    Local oscillator (LO)
    The receiver's own copy of the carrier. It is split into a 0° and a 90° version to produce I and Q; every imperfection in that split shows up as a distortion of the constellation.
    Quadrature skew
    The error in that 90° split. It shears the constellation, so a square 16-QAM grid turns into a parallelogram.
