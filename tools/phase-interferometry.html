    What the controls are teaching

    A baseline shorter than half a wavelength can never hide a cycle, because the largest phase difference it can produce is 180°. That makes it honest but coarse: its whole angular range is squeezed into one sawtooth, so a degree of phase error becomes a large angle error. Stretch the baseline with the scale control and the sawtooth repeats several times across the same sweep — each repeat is a candidate angle the receiver cannot tell apart from the true one.

    The chain is how a real receiver escapes that. Solve the short baseline first, predict what the next baseline should read, and pick the cycle count that lands nearest the reading. It survives as long as each jump in spacing is small enough that the previous estimate points at the right cycle — roughly a factor of four when the phases are clean. Raise the phase-noise control and the chain starts guessing wrong at the long end first, which is exactly the failure a calibration campaign is trying to prevent.

    Honest limits of this model

    Plane waves only: the emitter is treated as infinitely far away, so the wavefronts across the array are parallel and the geometry is one-dimensional. Real arrays see curvature at close range, mutual coupling between elements, and per-channel phase offsets from cable lengths that must be calibrated out. Amplitude is uniform here; a real element pattern rolls off toward endfire, where this tool still reports a confident angle.

    Glossary
    Angle of arrival (θ)
    The direction the signal comes from, measured from straight ahead.
    Baseline (d)
    The distance from the reference element A1 to another element.
    Wavelength (λ)
    The distance between two wave peaks; λ = c / f.
    Phase difference (Δφ)
    How much later the wave arrives at one element than at A1, in degrees.
    Wrapping
    A receiver reads phase only modulo 360°; whole cycles vanish from the reading.
    Ambiguity
    When d > λ/2, several different angles produce the same wrapped phase.
    Velocity factor
    Propagation speed as a fraction of c. Below 1 the wavelength shortens.
    Geolocation
    Working backwards from the measured phases to the emitter's direction.
