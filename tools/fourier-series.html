    Glossary
    Fundamental
    The base sine, one cycle per repeat of the target. Every other ingredient is a multiple of it.
    Harmonic n
    A sine at n times the fundamental frequency.
    Coefficient bn
    How much of harmonic n the recipe calls for. A negative value flips the sine upside down.
    Fourier series
    The recipe itself: the full list of coefficients that rebuilds the repeating wave exactly.
    Spectrum
    The recipe drawn as bars, one per harmonic. The right-hand plot is a spectrum.
    Gibbs effect
    The overshoot spikes beside any sharp jump. More harmonics make them narrower but never shorter — about 9 % remains.
    rms
    Root mean square — an average size for a wiggly difference, ignoring its sign.
